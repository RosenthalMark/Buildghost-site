03b / execution trace

Step-by-step
toolpath.

The exact order of execution — loops included. Every handoff is deliberate.

14 steps / 3 feedback loops
  1. ScrapeTag  — 01

    Scrape & Map

    Scrapes the target site, maps the full DOM selector tree, and generates validated smart tags.

  2. CASPER  — 02

    Metadata ingestion & test strategy

    Processes the ScrapeTag metadata map and outputs a structured test strategy.

  3. Playwright  — 03

    Scaffold tests & happy paths

    Receives the CASPER strategy and scaffolds initial Playwright tests covering all happy-path flows.

  4. Trace  — 04

    A/B funnel experimentation

    Executes a coin-flip A/B bucket experiment on the payment funnel. Logs every pass and failure.

  5. CASPER  — 05

    Ingest trace logs & update strategy

    Loops back to digest Trace outputs and refines the test strategy with targeted edge-case coverage.

    ↩ Loop back
  6. Playwright  — 06

    Append edge-case tests & sign-off

    Appends the CASPER-directed funnel edge cases to the test suite and prompts the user for sign-off.

    ↩ Loop back
  7. CASPER  — 07

    Handoff to GhostWriter

    Packages the approved test suite and hands it off to GhostWriter for dependency setup and CI/CD ingestion.

    → Handoff
  8. GhostWriter  — 08

    Dependencies, scaffold & Docker pipeline

    Installs dependencies, scaffolds the boilerplate harness, injects the tests, and spins up a Docker/K8s CI/CD container.

  9. Release Readiness Gatekeeper  — 09

    Scan & score — 88

    Analyzes the test run, weighs signals, and scores the release candidate. Initial score: 88 / 100. Details the exact corrective actions needed.

  10. CASPER + Unit Test Tool  — 10

    Generate & run unit tests

    CASPER generates and runs the recommended unit tests, reporting status back to the gatekeeper loop.

  11. Release Readiness Gatekeeper  — 11

    Re-score — 96 / Pass

    Re-evaluates the candidate with unit tests included. Score climbs to 96 / 100. Gates pass.

    ↩ Loop back ✓ Pass
  12. GhostWriter  — 12

    Cut branch, push & merge

    Cuts the release branch, pushes the codebase, and merges the pull request — with explicit user approval.

    ↩ Loop back
  13. SignalDeck  — 13

    Live telemetry, ELK logging & PagerDuty

    Takes over the operations phase. Provides Datadog/ELK-style monitoring, historical drill-down, and a PagerDuty-style alerting loop.

    → Ops handoff
  14. Horizon Marketplace  — 14

    Developer marketplace extension loop

    Future extension point — engineers submit custom modules (free or paid), establishing BuildGhost as the definitive all-in-one SDLC platform.

    ◆ On the horizon
